# API documentation

The OpenAPI document is generated by Scramble (`config/scramble.php`, `src/Shared/Infrastructure/Documentation/ApiDocumentation.php`). The pages `/docs/api` and `/docs/api.json` are served only outside production; `php artisan scramble:export` writes `api.json` (git-ignored) in every environment.

## Keeping the document complete

- Response bodies are documented: a list is returned as `XResource::collection(PaginatedResources::paginator(...))` or `XResource::collection($page->items)->additional(CursorResources::envelope(...))` (never through a class-string helper, which hides the resource from the generator); loose fields of a resource carry a `/** @var ... */` comment above their key (a docblock on `toArray()` is ignored); a 204 is `response()->noContent()`.

## Error codes

`docs/api/error-catalog.md` is generated from the source by `php artisan api:error-catalog` (`--check` fails when the file is stale; a unit test runs it, so run the command after adding or changing an error code). The same table is the "Errors" section of the OpenAPI document.
